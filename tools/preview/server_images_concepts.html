Server images in chat

Mock-up set J (D189 to D198). An admin puts one PNG per server in config/bsp_server_utilities/server_images/ on any server, named as Velocity knows it (BSP-Spawn.png), and presses REFRESH: that folder becomes the network's set. Staff then see each server's image in place of the grey [BSP-Spawn] in front of chat from other servers. The chat part is decided; the three looks below are for the SERVER IMAGES tab. Sample data and made-up images; the size is the game's at GUI scale 1.5.

Decisions

  1. J1 the tab's look: A a list of servers with the picked one's details, previews and sample line beside it; B one table of every server with its image at x2 and a strip of all images; or C a large chat box with a sample line per server and a "to fix" list under it.

  3. J3 REFRESH: asks SURE? only when it would remove or replace an image already in use (as described), or always asks.
