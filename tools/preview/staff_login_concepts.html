Staff panel: mock-up set N, logging in and staff accounts

Three looks for the panel's own login (after Cloudflare's emailed code), setting up a login from a one-time link (password, then the authenticator QR code and a code to prove it was scanned), and the Owner's STAFF ACCOUNTS page (D248, D250, D280 to D283). Then two ways to show the ten backup codes once. Phone frames, the BSP website's colours. Names, addresses and codes are made up.

A. One card

Everything on one calm card in the middle of the screen. The login asks for the password and the code together. Setting up is one page with three numbered parts. The staff page is a list of people, each with a ⋯ menu for their actions.

A1, log in
A2, set up from a link
A3, staff accounts (Owner)

B. Steps

One thing per screen with a progress bar. The login asks for the password, then the code in six big boxes (the phone's number pad opens; most authenticator apps fill it in with one tap). Setting up is four steps: password, scan, code, backup codes. The staff page shows each person's actions as keys under their name.

B1, log in, the code step
B2, set up, the scan step
B3, staff accounts (Owner)

C. Game panel

The look of BSP's in-game screens: Silkscreen titles, square keys, a teal frame for staff and violet for the Owner's pages, like the admin panel in game. The login shows how many tries are left after a mistake. The staff page reads like the STAFF tab's rows.

C1, log in, after a wrong try
C2, set up from a link
C3, staff accounts (Owner)

The ten backup codes, shown once: two ways

After the code from the app is right, the ten backup codes appear once (D283). Any of these goes with any look above.

Choices

  1. N1. The look. A: one calm card, everything on one page. B: one step per screen with big code boxes, the easiest on a small phone. C: BSP's in-game screen look, square keys and Silkscreen titles, matching the game.
  2. N2. The backup codes. A list with COPY ALL and SAVE AS FILE, and a tick "I have saved these" before going on. A grid sized for a screenshot or printing, with the same tick. One code at a time is not offered, as it is slow; say if you want it.
  3. N3. What the Owner sees first after logging in when someone was locked out. A gold line at the top of the staff page ("1 lock-out since your last visit", as in A3 and B3). A card on the players screen too, so it is seen at once.
