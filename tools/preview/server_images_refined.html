Server images: the SERVERS tab, refined

Look A as picked (D199), named SERVERS (D200), with REFRESH asking SURE? only when it would remove or replace an image in use (D201). Three points to confirm before building, R1 to R3. Sample data.

R1: which servers the list shows, and in what order

Every name in one alphabetical list: this server (marked here), the servers running now, and every name that has a file in the set even if that server is down. A name not heard from in the last minute is marked off, and a file named after a server never heard from is marked ? (here BSP-Wild, perhaps a misspelling). It opens on this server.

R2: what REFRESH says before it changes images in use

The first click reads the folder; if anything in use would be replaced or removed, the footer turns red and names them, and the key becomes SURE? for three seconds. A refresh that only adds images, or changes nothing, goes through on the first click and the footer says what it did ("2 images added", "Nothing changed").
