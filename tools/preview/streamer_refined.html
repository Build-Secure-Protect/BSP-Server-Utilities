Streamer Mode: look C refined (set AU)

Look C as picked (D713): a first page with the switch, the output, the frame rate, a live preview of what OBS gets and a tile per mod; a page per mod. Each frame is the 480 × 270 GUI-pixel screen (1920 × 1080 at GUI scale 4); the large ones are drawn 1.5 times bigger. Mods, items and counts are this pack's; the world is a drawn stand-in.

R1. The first page, on, with the stream window

The green line says the stream window is open and how to add it in OBS. The preview is the stream picture itself, live (here the minimap and F3 are gone from it). A tile's count turns teal when anything in it is hidden. The key is set in Controls › Key Binds › BSP Server Utilities.

R2. The output's states

On Windows with Spout2 chosen: no window opens; OBS takes it with the Spout2 plugin's source.
On a Mac: Spout2 is greyed out and says why when hovered.
Off: no stream window and nothing sent. The choices can still be set beforehand.

R3. A mod's page

Minecraft. With "Chat: all of it" hidden, the line rule above it is covered and greyed. HIDE ALL and SHOW ALL for the whole page.
BSP-Teleport, before its update: the gold line says the whole band and portal screen are hidden until then. After the update the gold lines go and only the numbers are hidden.
Other mods: every HUD part the other mods register, grouped by mod and read from the game, so a mod added later appears by itself. All shown at first.

R4. The eye key

The pause screen in singleplayer or on a server, Streamer Mode off: a dim eye in the top-right corner, its name on hover.
The title screen (the pack's FancyMenu layout behind it), Streamer Mode on: ringed red with a red dot.

R5. What OBS gets

BSP Stream
The stream window (a Mac here): titled "BSP Stream", the game's size by default, resizable. The player is in game: no minimap, no F3, the hotbar as usual.
The player has JourneyMap's full-screen map open: the stream shows the game behind it and the "Menu hidden" card.
